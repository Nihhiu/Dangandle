    How to play

    1. One character is hidden. You have 10 attempts to name them.
    2. Type a name and pick a suggestion (aliases like Keebo or Celeste work too).
    3. Every guess is compared with the secret on nine attributes: title, gender, height, weight, status, talent type, likes, dislikes and debut game.
    4. A new puzzle is generated every day from the date as a seed — everybody plays the same character on the same day.
    5. The counter shows how many characters are still consistent with every clue you have seen.
    6. Progress and statistics are stored in this browser only.

    Clues

    • Exact — the attribute matches the secret.
    • Partial — close, but not identical (same series, same role word, near value…).
    • None — the attribute has nothing in common.
    • Unknown — the secret has no data for that attribute.
    • ↑↓Arrows — the secret is taller / shorter or heavier / lighter than your guess.

    Likes & dislikes

    The Likes and Dislikes of every character are the ones listed on their official profile on the Danganronpa Wiki. When the whole list matches the secret the cell turns green, when only some entries are shared it turns yellow, and when nothing matches it turns pink.
